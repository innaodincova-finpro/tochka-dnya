# Точка дня

Личный органайзер для ежедневных планов, заметок и контроля расходов. Приложение работает прямо в браузере и устанавливается на экран телефона как обычное приложение.

**Открыть приложение:** https://innaodincova-finpro.github.io/tochka-dnya/

## Что внутри

- **Сегодня** — приветствие по времени суток, ближайшее событие и дела на день.
- **План** — непрерывный календарь по месяцам; записи видны прямо на датах, а нажатие открывает день. Для события можно указать время и адрес.
- **Заметки** — обычные записи, задачи и списки с интерактивными галочками.
- **Финансы** — ежедневные расходы, категории, статистика за неделю, месяц или свой период.
- **Ещё** — имя, валюта, инструкция, резервная копия и сведения о приложении.

## Первый запуск

1. Откройте ссылку приложения.
2. Введите имя для приветствия и выберите валюту.
3. Добавьте первое дело, заметку или расход кнопкой **«+ Добавить»**.

Приложение передаётся без чужих записей. До подключения аккаунта новые данные остаются только в браузере пользователя.

После подключения облачного сохранения записи дополнительно синхронизируются с защищённым аккаунтом пользователя. При первом входе существующие локальные записи отправляются в облако; при входе на новом устройстве данные восстанавливаются автоматически.

Каждое изменение сохраняется автоматически. В верхней части экрана показывается время последнего автосохранения. Если резервную копию не делали семь дней, приложение напомнит сохранить её файлом.

## Установка на телефон

### iPhone / iPad

1. Откройте приложение в **Safari**.
2. Нажмите **«Поделиться»**.
3. Выберите **«На экран Домой»**, затем **«Добавить»**.

### Android

1. Откройте приложение в **Chrome**.
2. Нажмите меню **⋮**.
3. Выберите **«Установить приложение»** или **«Добавить на главный экран»**.

После первого открытия приложение доступно и при временном отсутствии интернета. Автосохранение защищает записи при обычном закрытии приложения, но не при очистке данных браузера или потере телефона. Поэтому используйте **Ещё → Резервная копия**; приложение напоминает об этом раз в семь дней.
