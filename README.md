# Точка дня

Личный органайзер для ежедневных планов, заметок и контроля расходов. Приложение работает прямо в браузере и устанавливается на экран телефона как обычное приложение.

**Открыть приложение:** https://innaodincova-finpro.github.io/tochka-dnya/

## Что внутри

- **Сегодня** — приветствие, просроченное, что дальше по плану и дела на день.
- **План** — непрерывный календарь по месяцам. Цвет даты показывает состояние: запланировано, прошло и не отмечено, всё отмечено. Нажатие открывает день.
- **Заметки** — три вкладки: дела с галочками, заметки и списки по пунктам. Поиск по всему приложению, необязательная тема для отбора, закрепление наверху, дописывание голосом.
- **Финансы** — расходы и доходы за период, категории, остаток.
- **Ещё** — имя, облачное сохранение, резервная копия.

## Как устроены экраны

При открытии всё свёрнуто: виден только заголовок блока и короткий итог. Нажатие раскрывает содержимое, повторное — сворачивает. Кнопка «свернуть» есть и сверху, и под раскрытым содержимым.

Диктовка — основной способ ввода. Список продуктов раскладывается по пунктам сам, время «1015» превращается в 10:15, дробный вес в любой формулировке приводится к одному виду.

## Первый запуск

1. Откройте ссылку приложения.
2. Введите имя для приветствия и выберите валюту.
3. Добавьте первое дело, заметку или расход кнопкой **«+ Добавить»**.

Приложение передаётся без чужих записей. До подключения аккаунта новые данные остаются только в браузере пользователя.

После подключения облачного сохранения записи дополнительно синхронизируются с защищённым аккаунтом пользователя. При входе записи с телефона и записи из облака складываются, а не заменяют друг друга: то, что внесено до входа, не стирает уже сохранённое, и наоборот. Удалённые записи остаются удалёнными — отметка об удалении хранится полгода. Если пароль забыт, в окне входа есть «Забыли пароль?»: письмо для смены придёт на указанную почту.

Каждое изменение сохраняется автоматически; состояние показано в верхней части экрана. Если резервную копию не делали семь дней, приложение напомнит сохранить её файлом.

## Установка на телефон

### iPhone / iPad

1. Откройте приложение в **Safari**.
2. Нажмите **«Поделиться»**.
3. Выберите **«На экран Домой»**, затем **«Добавить»**.

### Android

1. Откройте приложение в **Chrome**.
2. Нажмите меню **⋮**.
3. Выберите **«Установить приложение»** или **«Добавить на главный экран»**.

После первого открытия приложение доступно и при временном отсутствии интернета. Автосохранение защищает записи при обычном закрытии приложения, но не при очистке данных браузера или потере телефона. Поэтому используйте **Ещё → Резервная копия**; приложение напоминает об этом раз в семь дней.

## Календарь айфона

События и записи со сроком можно подписать в системный календарь: настраивается один раз, дальше они появляются там сами и напоминают о себе. Установка — в [supabase/KALENDAR.md](supabase/KALENDAR.md).
