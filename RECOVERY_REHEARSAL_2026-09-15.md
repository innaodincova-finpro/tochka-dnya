# Репетиция восстановления «Точки дня»

Дата: 15 сентября 2026 года.

## Результат

Бесплатная изолированная репетиция восстановления выполнена в локальном PostgreSQL-движке PGlite. Рабочий проект Supabase и реальные пользовательские записи не изменялись.

Проверено:

- создание контрольной схемы основных объектов «Точки дня»;
- резервирование каталога PostgreSQL;
- имитация потери исходных данных;
- запуск новой пустой базы из резервной копии;
- совпадение количества строк и SHA-256 содержимого до и после восстановления;
- сохранность JSON с заметками, событиями и финансами;
- сохранность связей пользователей, документов, push-подписок и метаданных файлов;
- наличие двух обязательных индексов после восстановления.

Автоматическая команда: `npm run test:recovery`.

## Сверка с рабочей базой

Перед репетицией состав основных объектов рабочей базы проверен только чтением.
Пользовательские записи, количества строк и контрольные суммы в публичный
репозиторий не переносятся.

## Граница результата

Это подтверждает техническую работоспособность резервирования и восстановления PostgreSQL-данных в изолированной среде. Не проверены перенос Supabase Auth, секретов Edge Functions и самих файлов Storage: бесплатный тариф не предоставляет третий активный проект для полной облачной репетиции. Эти ограничения не следует считать выполненными.
