# PLAN-IMPORT-01 — локальный разбор источников

8 октября 2026. Начат по команде владельца «Переходим к точке дня». Это первый технический пакет согласованного маршрута; интерфейс, опубликованное приложение, Supabase и пользовательские данные не менялись.

## Сделано и проверено

Независимые модули `schedule-import.mjs` и `schedule-source-base.mjs` разбирают Excel .xlsx, CSV, ICS и университетский текст без сети и записи в хранилище. Результат содержит записи, непрочитанные строки и вопросы; данные не сохраняются автоматически. Даты без года не угадываются, часовой пояс ICS выбирается явно, события без времени сохраняют пустое время. Формулы CSV не исполняются; повреждённая структура блокируется.

Excel сохраняет начало/окончание, вид занятия, преподавателя, плановый характер действий и период сессии. Проверенная книга: 175 записей (112 занятий, 63 действия, включая 25 тестов), 0 неразрешённых строк. Все разобранные поля совпали с независимым результатом сверки первоисточника. Персональный источник и строки аккаунта в Git не входят.

ICS сохраняет UID/SEQUENCE и справочные поля. Повторы, исключения, отмены, несовместимые часовые пояса и многодневные события со временем пока выдаются как требующие уточнения; они не превращаются молча в одно событие. Поддержка полного набора ICS не заявляется.

16/16 адресных проверок пройдены. Полный `npm test` успешен, включая действующие проверки сохранности данных, календаря и push. Новый набор включён в обязательный `npm test`. Проверки выполнялись локально; это не проверка опубликованного приложения или реального аккаунта.

## Не сделано

Подключение к «Плану», режимы «Личный / Учебный / Все», выбор записей и уточнение вопросов в интерфейсе, устойчивое сопоставление между загрузками, защита ручных правок и удалений, атомарное сохранение, отображение начала/окончания и периода сессии. PDF/фото/скриншоты пока не подключены. Релиз, реальная загрузка и проверка доставки на телефоне не выполнялись.

## Следующий шаг

Подключить согласованные экраны и предварительный просмотр к действующему «Плану». Старые записи считать личными; общий просмотр не создавать копированием. Для ICS использовать UID и явно показывать изменение SEQUENCE. Для иных источников показывать возможные переносы как вопросы, не перезаписывать ручные изменения. Ручное удаление импортированной записи должно учитываться при повторной загрузке. Смена аккаунта закрывает незавершённую загрузку.

Поставщик распознавания PDF/изображений и условия передачи файлов ещё не выбраны. По REQUIREMENTS.md эти вопросы обсуждаются до зависимой реализации. Новые платные вызовы или передача источников не выполнялись. Перед установкой требуется отдельное согласие владельца по AGENTS.md; готового пакета для установки сейчас нет. Для выполненного локального разбора участие владельца не требуется.
