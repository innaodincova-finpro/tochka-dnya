# Офлайн-приёмка «Точки дня»

Дата: 15 сентября 2026 года.

## Автоматизировано в настоящем Chromium

- первое открытие с сетью и установка Service Worker;
- повторное открытие приложения без сети из кэша;
- создание заметки без сети;
- закрытие вкладки и повторное открытие без сети;
- сохранность офлайн-записи;
- восстановление сети;
- получение новой версии Service Worker;
- удаление старого кэша приложения;
- сохранность пользовательских данных после обновления кэша.

Сценарий запускается в GitHub Actions файлом `offline-browser.cjs`.

## Не подменяем автоматическим тестом

Отправка офлайн-изменения в реальный Supabase после возврата сети требует отдельной тестовой учётной записи. Рабочую личную запись и реальные данные для CI использовать нельзя. Этот пункт остаётся ручной приёмкой: войти в тестовый аккаунт на двух устройствах, отключить сеть, создать запись, вернуть сеть и подтвердить появление записи на втором устройстве без дубля и конфликта.
