# Изолированный тестовый календарь помощника

Узкий тестовый экран календаря: добавить подтверждённую встречу из sandbox,
показать на дате, изменить название, дату, время, место. Не полная копия UI.
Формат встречи и mergeThree/normalize/validateData взяты из index.html
рабочей версии ca04694eae174596e6f613f1fd0464f77d6a6dd1 (5.8.13).
Core извлечён без изменения функций; отдельный uid только для заполнения
недостающих идентификаторов при normalize.

Новая функция tochka-assistant-calendar: JWT=true, Auth owner email check.
Данные только в дополнительных колонках tochka_assistant_sandbox.
Нет запросов user_app_data, push, Telegram, DeepSeek, Auth admin mutations.
Первичное добавление берёт серверный подтверждённый черновик, требует event.
Идентификатор детерминирован по владельцу и source_version.
Повторный импорт не затирает редактированную встречу.
Другая версия черновика считается отдельной записью, семантического dedup нет.
Изменения с compare-and-swap calendar_revision; устаревшая правка получает409.
UI объединяет разные поля через исходный mergeThree, максимум3попытки.
Конфликт одного поля не перезаписывается. Ввод пользователя остаётся в форме.
Сессия и несохранённые поля только в памяти, закрытие страницы их теряет.
Обновление с другого устройства через кнопку. Нет offline/background sync.
Список ограничен100последними подтверждёнными черновиками.
Время отображается как указанное пользователем, без конвертации часового пояса.

Проверки из корня с установленными npm dependencies:
node --test assistant-lab/calendar/test.mjs
node assistant-lab/calendar/ui-test.mjs
Тесты: fake API/Auth, локальный PGlite; никакие реальные записи не изменяют.
Реальная приёмка владельцем после публикации остаётся отдельным шагом.

Публикация web/* в /tochka-assistant/ GitHub Pages владельца.
core.mjs дублируется как web/calendar-core.mjs для браузера.
Миграция schema.sql добавляет только nullable event и revision=0.
Откат: убрать календарную страницу/функцию, оставить колонки для сохранности.
Рабочее приложение и receiver не изменяются.
